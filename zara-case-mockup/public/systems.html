THE NOVELTY ARGUMENT, MADE FALSIFIABLE

Six systems. Four already run in production.

"The pieces exist but nothing is integrated" is true and unfalsifiable as stated. Naming the systems and marking which already exist turns it into a claim a Zara judge can check — and it is the line that separates this from four other teams pitching a resale app.

THE CANNIBALISATION ANSWERThe pre-owned option only appears where the size is sold out, so there is no new unit to lose — that sale was already gone. This argument exists only because the trigger is demand-side, and Zara will ask it. Put it on the slide rather than saving it for Q&A.
THE CATALOGUE ANSWERZara Pre-Owned is already live in 17 markets with repair, resell and donation and a browsable page. Say so in one line, then draw the distinction: a catalogue is a destination you have to decide to visit, and we are putting the decision inside the flow people are already in.
